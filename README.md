# Pellarno

Website for a Florentine leather workshop that designs and makes leather goods to order. The public name is Pellarno, set in `src/main.ts` (`NAME`).

Plain HTML, CSS and a small script, built with Vite. Deployed on Vercel.

## Sections
Hero, Su misura (design, prototype, leather and colour, production), what we make, the leathers, hardware and finishing, Le creazioni, L'atelier, Florence and leather, Houses we have produced for, FAQ, contact form.

## Edit
- Copy and photos: `index.html`
- Colours and type: top of `src/style.css`
- Houses: `HOUSES` in `src/main.ts`; logos in `src/logos/` (official, from Wikimedia Commons)
- Images: `public/img/` (`p` = photo in its own setting, `c` = cut out, `mat-` = material photos from Unsplash, `h` = hardware, `o` = earlier factory photos; `-s` = phone size)

## Run
```
npm install
npm run dev
npm run build
```
